# Historial limpio

**Nivel:** Fácil

## Descripción
Limpiar el historial de navegación del usuario eliminando duplicados y vacíos.

## Objetivo
Implementa una solución en Java que cumpla con la lógica descrita. Usa la plantilla `Main.java` para comenzar.

## Cómo empezar
1. Clona este repositorio.
2. Dirígete a la carpeta `Historial_limpio`.
3. Abre `Main.java` y escribe tu solución.
4. ¡Comparte tu solución con la comunidad!
